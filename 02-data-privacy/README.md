## What is data privacy?

Data privacy concerns **personal data**: information relating to an identified or identifiable individual. It governs the entire data lifecycle:

- how personal data is collected and stored,
- where it is stored,
- how long it is retained and when it must be deleted,
- and the rights individuals have over their data.

## Security vs privacy: the key distinction

**Strong security does not guarantee privacy.**

> Example: health data is encrypted (security) but sold to an advertiser without consent. That is a privacy violation.

**Rule:** security protects data; privacy governs its authorized use.

## Core privacy principles

| Principle | Meaning |
| --- | --- |
| Purpose limitation | Use data only for the reason it was collected. |
| Data minimization | Collect only what is necessary. |
| Storage limitation | Delete data once it is no longer needed. |
| Individual rights | Right to access, correction, erasure ("right to be forgotten"), portability and so on. |

## Data privacy policy

Every enterprise has a data privacy policy that defines how personal data may be collected, used, shared, retained and deleted, and the rights of individuals (customers, employees and others).

**Applies to:** personal data (PII, PHI, PCI and similar).

Typical coverage:

- Lawful basis and consent
- Purpose limitation
- Data minimization
- Retention and deletion rules
- Data subject rights (access, correction, erasure)
- Third-party data sharing rules
